# Weiqi Tutor

围棋启蒙模型：输入一道简单死活题，理解局面与题目要求，判断正解/错解，并用初学者能听懂的语言解释变化过程。

## 当前阶段

本仓库优先建设可验证的数据与棋理层，而不是先做聊天 UI 或直接微调模型。

1. 解析 SGF 棋盘、先手、注释和变化树。
2. 提取题目分支，并区分正解、错解、变化和未标注分支。
3. 用规则计算验证每一步的棋理事实。
4. 生成结构化监督样本，再训练和评估启蒙模型。

## 已实现

- SGF 基础解析与题目答案分支提取。
- 围棋棋盘规则核心：连通块、气、提子、自杀禁入、劫点和重复局面检查。
- 对提取出的分支逐手回放，输出每手是否合法及棋理事实（提子数、己方气数、相邻敌我棋块、打吃数量等）。

## 开发

要求 Node.js >= 20。

```bash
npm install
npm run typecheck
npm run build
npm run audit:sgf -- ./path/to/sgf-directory
```

## 复用来源

题库与部分围棋基础设施来自项目所有者的 [weiqi-bot](https://github.com/zhangbin2025/weiqi-bot)。

## 设计原则

**规则负责判定，模型负责理解与表达。** 正误标签、提子、气、连接等可验证事实不能交给语言模型猜测。
