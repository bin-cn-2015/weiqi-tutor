# Weiqi Tutor

围棋启蒙模型：输入一道简单死活题，理解局面与题目要求，判断正解/错解，并用初学者能听懂的语言解释变化过程。

## 当前阶段

本仓库优先建设可验证的数据与棋理层，而不是先做聊天 UI 或直接微调模型。

1. 解析 SGF 棋盘、先手、注释和变化树。
2. 提取题目分支，并区分正解、错解、变化和未标注分支。
3. 用规则计算验证每一步的棋理事实。
4. 生成结构化监督样本，再训练和评估启蒙模型。

## 开发

要求 Node.js >= 20。

```bash
npm install
npm run typecheck
npm run build
```

## 复用来源

题库与部分围棋基础设施来自项目所有者的 [weiqi-bot](https://github.com/zhangbin2025/weiqi-bot)。本项目先以独立、可审计的数据处理核心为边界，避免直接耦合整个应用。

## 设计原则

**规则负责判定，模型负责理解与表达。** 正误标签、提子、气、连接等可验证事实不能交给语言模型猜测。
